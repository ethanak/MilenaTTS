# MilenaTTS
Mbrola based Polish language TTS system

System TTS dla języka polskiego bazowany na syntezatorze Mbrola

As the content is only of interest to Polish speakers, the rest of the documentation and the remaining files are in Polish.

Jako że zawartość jest interesująca wyłącznie dla osób posługujących się językiem polskim, dalsza część oraz pozostałe pliki dokumentacji są w języku polskim.

## milena



Kompletny system TTS wraz z bibliotekami.

Konieczne do instalacji pakiety i najprostszy sposób instalacji: [ubuntu installer](milena/ubuntu_install_milena.sh)
